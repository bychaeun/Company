# CHAE EUN.ZIP — 채은 지식 저장소

말랑한 푸딩 디자인의 개인 업무 메모 저장소입니다.

- Google 로그인 + 관리자 승인 후 메모 열람
- 사이트 또는 Google Sheets 접근관리 탭에서 승인·거절·차단
- 비공개 시트 메모 검색, 대분류·소분류 자동 생성
- 승인된 계정만 볼 수 있는 Google Drive 이미지
- 메모 PNG 저장 및 웹앱 설치
- 서버 실행 중 30분 동기화, 휴면 후 재접속 시 갱신

코드는 공개여도 서버의 메모/이미지 API는 승인된 계정만 사용할 수 있습니다.
인증 설정이 없으면 접근을 허용하지 않습니다. Node.js 24 서버가 필요하며 GitHub Pages로 운영하지 마세요.

[SETUP.md](SETUP.md)에 Google 인증 설정과 무료 Render 배포 안내가 있습니다.
실제 서비스 활성화에는 OAuth 클라이언트, 시트 서비스 계정, 호스팅 계정 설정이 필요합니다.
